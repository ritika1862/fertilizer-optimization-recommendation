💡 About the Recommendation System

AgriSmart uses a machine learning classification model trained on fertilizer and soil-related agricultural data. The system analyzes the submitted crop and soil parameters and predicts the fertilizer most suitable for the given conditions.

The recommendation is intended as a decision-support tool. Actual fertilizer application should also consider agricultural expert advice and local soil conditions.
